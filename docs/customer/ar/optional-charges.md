# رفض الرسوم الاختيارية وفهم التسعير النسبي

ألغِ شراءً اختياريًا دون الخلط بينه وبين فاتورة التجديد.

تاريخ المراجعة: 2026-10-05

## الفواتير الاختيارية

يظهر رفض الرسوم أو إلغاؤها للفواتير الاختيارية غير المدفوعة المؤهلة فقط، مثل طلب ترقية أو شراء سعة أو إضافة. يلغي الإجراء الطلب ويعالج الرصيد المحجوز المرتبط به. لا يُستخدم لرفض تجديد اشتراك فعّال أو عكس تغيير مدفوع طُبّق بالفعل.

## الوقت غير المستخدم والرصيد

قد تُحسب مشتريات منتصف الدورة حسب المدة المتبقية إلى التجديد. تراعي ترقية الخطة القيمة المدفوعة للوقت غير المستخدم عبر التسعير والفواتير والمحفظة. قد يضيف تحرير الأماكن الشاغرة للبيئات قيمة المدة المتبقية إلى المحفظة. حذف الخادم وحده يُبقي المكان محجوزًا. فئات التشغيل الأقل لا تعيد قيمة الفترة الحالية. راجع الرسوم والرصيد الفعليين قبل التأكيد.

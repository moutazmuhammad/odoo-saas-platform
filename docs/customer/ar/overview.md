# التعرّف على VELTNEX

تعرّف على الاستضافة والخدمات الجاهزة والمشاريع وبيئات العمل.

تاريخ المراجعة: 2026-10-05

## المفاهيم الأساسية

توفّر VELTNEX بنية استضافة مُدارة لتطبيق Odoo ولوحة تحكم للعميل. تتيح اشتراكات الاستضافة إدارة قواعد البيانات وأدوات التطوير، بينما تقدّم الخدمات الجاهزة تطبيقًا مُعدًّا مسبقًا بواجهة إدارة أبسط. تتحدد الخطط والمناطق والإصدارات والخدمات المتاحة حسب كتالوج المنصة.

| المفهوم | المقصود |
| --- | --- |
| المشروع | مساحة عمل للاستضافة ترتبط بـ Instance الخاصة ببيئة Production. |
| Instance | بيئة تشغيل للتطبيق لها مواردها وعنوانها وبياناتها. |
| Production | البيئة الرئيسية لبيانات العمل الفعلية. |
| Staging / Development | بيئات وفروع Git مستقلة داخل مشروع الاستضافة نفسه. |

## مسؤولياتك

استخدم لوحة التحكم لإدارة البنية والصلاحيات والفوترة والاستعادة. أما مستخدمو التطبيق وصلاحياتهم فتُدار داخل Odoo بشكل مستقل. احتفظ بنسخة قابلة للاستعادة قبل أي تغيير يحذف البيانات أو يستبدلها. استضافة إصدار Enterprise لا تُغني عن ترخيص Odoo Enterprise.

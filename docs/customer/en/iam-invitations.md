# Invite an existing account

Use an email-bound invitation to establish access safely.

Reviewed: 2026-10-05

## Create and accept an invitation

Where the access workflow requires an invitation, select the email, projects, roles, and environment scopes. The invitation can be sent using configured outgoing mail or shared as a copied link. The recipient signs in with an active account whose login matches the invited email, then accepts. Pending invitations do not provide accepted project access.

## Expiry and cancellation

Invitations expire after 7 days. A wrong signed-in account cannot accept them. Removing all pending grants invalidates the invitation’s access. If acceptance fails, check the login email, expiry, and whether access is still pending; ask the owner or access administrator for a new invitation if necessary. An invitation does not transfer ownership of an existing account’s password.

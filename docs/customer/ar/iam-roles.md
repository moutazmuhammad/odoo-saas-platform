# مرجع الأدوار الثابتة

قارن جميع الأدوار المحددة مسبقًا وطريقة جمعها.

تاريخ المراجعة: 2026-10-05

## دليل الأدوار

يشمل كل دور ثابت عرض المشروع والبيئة الأساسي داخل نطاقه. يعرض الجدول الإجراءات الإضافية. رموز الأدوار ومعرّفات الصلاحيات قيم تقنية، بينما تُعرّب التسميات الظاهرة.

| الدور | الوصول الإضافي |
| --- | --- |
| قارئ المشروع | عرض تفاصيل المشروع والمقاييس وبيانات البناء دون مخرجات السجلات. |
| قارئ السجلات | قراءة سجلات التطبيق ومخرجات Deployment. |
| مسؤول Deployment | تنفيذ Deployment للإعداد الموجود وتحديث وحدات القاعدة المحددة، وعرض بيانات البناء وقائمة القواعد. |
| مسؤول تشغيل Instance | بدء تشغيل البيئة وإيقافها وإعادة تشغيلها. |
| مسؤول إنشاء البيئات | إنشاء خوادم Staging وDevelopment ضمن السعة المحجوزة. |
| مسؤول حذف البيئات | حذف خوادم Staging وDevelopment وفرع Git اختياريًا. |
| مسؤول إنشاء قواعد البيانات | عرض القواعد وإنشاؤها. تتطلب النسخة المطابقة أيضًا تنزيل النسخ. |
| مسؤول النسخ الاحتياطي لقواعد البيانات | عرض القواعد والنسخ وإنشاء نسخ احتياطية. |
| مسؤول تنزيل النسخ الاحتياطية | عرض القواعد والنسخ وتنزيل النسخ المكتملة. |
| مسؤول استعادة قواعد البيانات | عرض القواعد والنسخ واستعادة القواعد أو اللقطات. |
| مسؤول حذف قواعد البيانات | عرض القواعد وحذفها نهائيًا. |
| مسؤول وصول قواعد البيانات | عرض القواعد وإعادة تعيين كلمات مرور مسؤوليها. |
| مسؤول SQL | عرض القواعد وتشغيل أداة SQL للقراءة فقط. |
| مسؤول Terminal | فتح Shell الخاصة بـ Instance. |
| مسؤول صلاحيات المشروع | إدارة الوصول ضمن صلاحياته ونطاقات البيئات الممنوحة له. |
| مدير المشروع | كل صلاحيات المشروع بما فيها الضبط والإجراءات التي تحذف البيانات، دون فوترة المالك أو مدير قواعد البيانات غير المقيّد. |

## جمع الأدوار بعناية

إنشاء النسخة وتنزيلها صلاحيتان منفصلتان. تتطلب النسخة المطابقة مسؤول إنشاء قواعد البيانات ومسؤول تنزيل النسخ. يحتاج النسخ بين البيئات تنزيل النسخ في المصدر والاستعادة في الهدف. قارئ السجلات لا يحصل على Deployment، وقارئ المشروع لا يحصل على مخرجات السجلات. امنح مدير المشروع فقط لمن يحتاج جميع إجراءات المشروع.

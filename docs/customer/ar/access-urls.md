# عناوين Instance وHTTPS والوصول للموقع

افهم النطاقات الفرعية والاتصال الآمن والصفحات العامة ودخول التطبيق.

تاريخ المراجعة: 2026-10-05

## عنوان Instance

اختر نطاقًا فرعيًا متاحًا وDomain توفره المنصة أثناء الإعداد. يحدد العنوان الناتج Instance، وقد تحصل البيئات على نطاق فرعي فريد مشتق من المشروع. الأسماء وبادئات القواعد معرّفات تقنية؛ فلا تفترض إمكان تغييرها بعد الإنشاء.

## HTTPS والوصول العام

يُعدّ التجهيز HTTPS عبر بنية المنصة. يحتاج إخفاق الشهادة أو التوجيه إلى تشخيص البنية وليس إعادة كلمة مرور القاعدة. عند وجود قاعدة العميل يصل الزوار إلى موقع أو تطبيق Odoo، وعند غيابها يرون صفحة عدم وجود قاعدة. تحدد إعدادات تطبيقك ما إذا كانت صفحة Odoo عامة.

## العناوين المخصصة والوصول

استخدم الفتح من صفحة Instance أو القاعدة للوصول إلى العنوان الصحيح. تضبط IAM في VELTNEX أدوات البنية، بينما يضبط Odoo مستخدمي التطبيق والمحتوى العام. لا تتيح اللوحة الحالية محررًا عامًا ذاتيًا لـ Domain مخصص أو نقل المنطقة؛ تواصل مع الدعم للتحقق من الإتاحة ومتطلبات النقل.

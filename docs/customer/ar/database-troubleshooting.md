# معالجة عمليات قواعد البيانات والاستعادة

عالج حدود السعة والتسمية والأرشيف والتوافق مع التطبيق.

تاريخ المراجعة: 2026-10-05

## أعراض شائعة

| العَرَض | الخطوة التالية |
| --- | --- |
| لا توجد قاعدة بعد | أنشئ قاعدة العميل أو استعدها من قواعد البيانات؛ تشغيل البنية وحده لا يجهّز بيانات عملك. |
| Production تسمح بقاعدة واحدة | استبدل القاعدة الموجودة أثناء الاستعادة، أو انسخها احتياطيًا واحذفها قبل إنشاء أخرى. |
| رفض اسم القاعدة | راجع الحروف الصغيرة والبادئة المطلوبة والفواصل وطول الاسم الكامل. |
| إخفاق الرفع | راجع الاتصال والأرشيف. اطلب رفعًا جديدًا من النافذة إذا انتهى الرابط، وتواصل مع الدعم لأخطاء التخزين أو CORS. |
| اكتملت الاستعادة لكن Odoo لا يعمل | راجع توافق إصدار Odoo الرئيسي والوحدات المخصصة المتاحة، وتقرير العملية وسجلات البدء. |
| المرفقات مفقودة | تأكد من أن النسخة تضمنت مجلد المرفقات وليست تفريغ القاعدة وحده. |
| العملية ما زالت جارية | لا تبدأ عمليات متعارضة. سجّل العملية والقاعدة واطلب من الدعم مراجعة تنفيذها. |

## معلومات تُرسل للدعم

أرسل البيئة المستهدفة واسم القاعدة الكامل ونوع العملية وصيغة الأرشيف وحجمه التقريبي وإصدار Odoo والوقت والخطأ الظاهر. لا ترفق نسخة عميل كاملة في بلاغ عام. اتفق على قناة آمنة إذا احتاج الدعم الملف.

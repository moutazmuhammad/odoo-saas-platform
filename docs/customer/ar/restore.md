# استعادة لقطة كاملة لـ Instance

استبدل البيانات الحالية بلقطة سابقة وتحقق من الاستعادة.

تاريخ المراجعة: 2026-10-05

## قبل البدء

استخدم Instance تعمل ولقطة مكتملة متاحة ودور **مسؤول استعادة قواعد البيانات**. راجع تاريخ اللقطة وبيئتها. استعادة اللقطة تشمل Instance بالكامل؛ استخدم استعادة قاعدة محلية إذا أردت استبدال قاعدة واحدة فقط.

## الاستعادة والتحقق

1. افتح اللقطات واختر الاستعادة للنسخة المطلوبة.
2. اقرأ تنبيه الاستبدال واكتب الاسم المطلوب في نافذة التأكيد كما هو.
3. ابدأ الاستعادة وانتظر أثناء انتقال Instance إلى التجهيز. تحاول المنصة أخذ لقطة أمان جديدة قبل الاستعادة.
4. بعد العودة إلى التشغيل، تحقق من القواعد والمرفقات وتسجيل الدخول والوظائف الأساسية.

## أثر الاستعادة

> تنبيه: تستبدل اللقطة المختارة القواعد والملفات والإعدادات التي شملها الالتقاط. تُفقد التغييرات اللاحقة ما لم تُحفظ في مكان آخر. لقطة الأمان لا تُغني عن نسخة نزّلتها وتحققت منها مسبقًا. نسّق توقف الخدمة وإعادة معالجة التكاملات مع فريقك.

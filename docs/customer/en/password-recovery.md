# Recover your VELTNEX password

Use an email verification code to reset your platform login.

Reviewed: 2026-10-05

## Reset your password

1. While signed out, choose **Forgot password?** on the Sign in page.
2. Enter your login email and request the code. The same confirmation appears whether or not an account exists.
3. Check your inbox and spam folder, then enter the newest code and a new password of at least 8 characters.
4. Complete reset and follow any remaining teammate setup steps if your account requires them.

## If the code does not arrive

Confirm the address is your login, allow time for queued mail, and request a new code when allowed. Repeated requests are rate limited. Contact support if delivery remains unavailable. Resetting the VELTNEX password does not reset any Odoo database administrator password.

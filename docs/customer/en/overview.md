# VELTNEX overview

Understand hosting, projects, and environments.

Reviewed: 2026-10-05

## Core concepts

VELTNEX provides managed Odoo hosting and a customer control panel. Each hosting project gives you Production, Staging and Development environments with database and developer tools. Available plans, regions, and versions depend on the platform catalog.

| Concept | Meaning |
| --- | --- |
| Project | A hosting workspace anchored by its Production instance. |
| Instance | A running application environment with its resources, address, and data. |
| Production | The main environment used for live business data. |
| Staging / Development | Separate environments and Git branches within the same hosting project. |

## Your responsibilities

Use the control panel to manage infrastructure, access, billing, and recovery. Configure business users and application permissions inside Odoo separately. Keep your own recoverable backup before destructive changes. Hosting an Enterprise image does not replace your Odoo Enterprise license.

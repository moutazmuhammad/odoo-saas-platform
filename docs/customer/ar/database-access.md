# مدير قواعد البيانات وكلمات مرور المسؤول

افتح أدوات الإدارة المصرّح بها وميّز صلاحيات المنصة عن صلاحيات Odoo.

تاريخ المراجعة: 2026-10-05

## فتح مدير قواعد البيانات

يستطيع المالك أو مسؤول المنصة فتح **مدير قواعد البيانات** من صفحة قواعد بيانات البيئة. ينشئ الزر وصولًا مصرحًا به إلى مدير Odoo دون كشف كلمة المرور الرئيسية. يستخدم أعضاء الفريق، بمن فيهم مديرو المشاريع، إجراءات لوحة التحكم التي تتحقق من الصلاحيات؛ ولا يمنح أي دور ثابت للفريق وصولًا غير مقيّد إلى مدير قواعد البيانات.

استخدم زر لوحة التحكم بدل حفظ رابط المدير أو مشاركته. يفتح العنوان الرئيسي لموقع الاستضافة التطبيق عند وجود قاعدة للعميل، ويعرض رسالة عدم وجود قاعدة عندما يكون فارغًا. صلاحية إدارة القواعد مستقلة عن زيارة عملاء صاحب الموقع لموقعه.

## إعادة تعيين كلمة مرور مسؤول القاعدة

1. بدور **مسؤول وصول قواعد البيانات**، اختر إعادة تعيين كلمة المرور للقاعدة المطلوبة.
2. حدّد كلمة مرور تستوفي متطلبات النافذة واحفظها بأمان.
3. استخدم اسم دخول المسؤول المعروض للقاعدة وكلمة المرور الجديدة للدخول إلى Odoo.

يغيّر الإجراء كلمة مرور مسؤول التطبيق في القاعدة، وليس دخول VELTNEX أو اعتماد اتصال PostgreSQL أو كلمات مرور مستخدمي Odoo الآخرين.

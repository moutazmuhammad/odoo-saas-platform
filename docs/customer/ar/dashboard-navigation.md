# بحث لوحة التحكم والإشعارات

تنقّل بسرعة وافهم التنبيهات التي تعرضها لوحة التحكم.

تاريخ المراجعة: 2026-10-05

## البحث والتنقل

افتح قائمة البحث من الشريط العلوي أو Ctrl/⌘ + K. ابحث عن المشاريع والصفحات والإجراءات المتاحة، واستخدم الأسهم وEnter للاختيار وEscape للإغلاق. يفصل محدد المشروع بين مشاريعك والمشاريع المشتركة. اختيار نتيجة لا يضيف صلاحيات لبيئة مقيّدة.

## الإشعارات والإجراءات المطلوبة

تبرز لوحة التحكم الدفع غير المكتمل والفواتير والـ Instances المخفقة أو المعلّقة والإشارات المتاحة للحساب. يلخص جرس الشريط العلوي هذه الإشارات ويربط بصفحاتها؛ وليس أرشيفًا دائمًا للإشعارات أو نظام قواعد تنبيه قابلًا للضبط. راجع الفاتورة أو الحالة الأصلية قبل التصرف. لا يرى أعضاء الفريق إلا البيانات التي تسمح بها صلاحياتهم.

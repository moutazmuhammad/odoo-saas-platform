# اختيار Workers والتخزين

حدّد الموارد حسب عبء العمل وحجم البيانات والاستخدام الفعلي.

تاريخ المراجعة: 2026-10-05

## الموارد التي تختارها

Workers هي عمليات معالجة طلبات Odoo وليست عددًا ثابتًا من المستخدمين المرخّصين. وتتأثر القدرة على العمل المتزامن أيضًا بـ CPU وRAM وكلفة الاستعلامات والوحدات المخصصة والمهام الخلفية. يشمل التخزين قاعدة البيانات وملفات التطبيق والمرفقات، بينما تُخزّن ملفات اللقطات بشكل مستقل.

## اختيار السعة والتحقق منها

1. اختر خطة منشورة أو موارد مخصصة مدعومة من صفحة الاستضافة.
2. قارن CPU وRAM والتخزين أثناء ذروة استخدام تمثل عملك الفعلي، وليس أثناء الخمول فقط.
3. زد الموارد عندما يؤثر الضغط المستمر على المستخدمين، وراجع أيضًا الاستعلامات المكلفة والكود المخصص.

# تغيير خطة الاشتراك

افهم الترقيات المرتبطة بالدفع والانتقال المجدول إلى خطة أقل.

تاريخ المراجعة: 2026-10-05

## قبل البدء

تغيير الخطة والسعة المشتراة من صلاحيات فوترة المالك. لا يمنح دور مدير المشروع لعضو الفريق هذه الصلاحيات. راجع الخطة الحالية والاستخدام ودورة الفوترة وأي فاتورة أو تغيير مجدول.

## كيف تُطبّق التغييرات؟

| التغيير | السلوك |
| --- | --- |
| الترقية | تُنشأ فاتورة ويُطبّق التغيير المدفوع بعد تسويتها، مع احتساب القيمة المدفوعة للوقت غير المستخدم ضمن التسعير والرصيد. |
| خطة أقل | تُجدول عند نهاية الدورة. يجب أن يقل استخدام التخزين عن 75% من حد الخطة المستهدفة ليترك 25% على الأقل شاغرًا؛ وقد يُرفض الطلب إذا كان الاستخدام مرتفعًا أو تعذّر قياسه. |
| إلغاء التغيير المجدول | يلغي الانتقال إلى الخطة الأقل قبل تطبيقه. |

## طلب التغيير

1. افتح Instance واختر **تغيير الخطة** أو **ترقية الخطة** للتجربة.
2. اختر الخطة والفوترة الشهرية أو السنوية وراجع التسعير.
3. أكمل الدفع إذا لزم أو أكّد التغيير المجدول إلى الخطة الأقل.
4. تحقق من الخطة الفعلية أو المجدولة في الملخص. قد يحتاج تطبيق الموارد إلى بعض الوقت.

# حذف قاعدة بيانات واستبدالها

افهم التأكيد وفقدان البيانات وإنشاء قاعدة بديلة.

تاريخ المراجعة: 2026-10-05

## قبل الحذف

> تنبيه: يزيل الحذف القاعدة المختارة وملفات التطبيق المرتبطة بها. لا يمكن التراجع عنه بإغلاق النافذة بعد التنفيذ. نزّل نسخة قابلة للاستخدام واختبرها أولًا؛ فالحذف ليس إجراء نسخ احتياطي.

## خطوات الحذف

1. استخدم دور **مسؤول حذف قواعد البيانات** في بيئة استضافة تعمل.
2. اختر الحذف للقاعدة واكتب اسمها الكامل كما هو للتأكيد.
3. انتظر اكتمال العملية. يمكنك بعدها في Production إنشاء قاعدة بديلة أو استعادة أخرى ضمن حد القاعدة الواحدة.

## ما الذي يبقى؟

حذف القاعدة لا يلغي Instance ولا يحرّر مكان البيئة المحجوز ولا يحذف فرع Git ولا يوقف فوترة الاشتراك. يعرض الموقع الفارغ رسالة عدم وجود قاعدة إلى أن تُنشأ قاعدة عميل أخرى أو تُستعاد.

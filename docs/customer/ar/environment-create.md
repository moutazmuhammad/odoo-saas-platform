# إنشاء بيئة Staging أو Development

استخدم مكانًا محجوزًا وفرع Git موجودًا أو جديدًا.

تاريخ المراجعة: 2026-10-05

## قبل البدء

- استخدم مشروع استضافة مدفوعًا بمستودع مرتبط بـ Production.
- تأكد من وجود مكان شاغر للنوع المطلوب وصلاحية **مسؤول إنشاء البيئات** لهذا النوع.
- تأكد من قدرة Token المستودع على قراءة الكود وتنفيذ عمليات الفروع اللازمة.

## خطوات الإنشاء

1. افتح مساحة المشروع واختر إنشاء Staging أو Development.
2. أدخل اسم البيئة، وهو مطلوب في Development. اختر فرعًا موجودًا أو حدّد فرعًا جديدًا؛ وإذا لم تحدّد فرعًا يُستخدم اسم البيئة.
3. أكّد الإنشاء وتابع التجهيز وبناء الكود الأول. ترث البيئة مستودع المشروع وإصدار Odoo.
4. افتح قواعد البيانات لإنشائها أو استعادتها، أو استخدم نسخ قواعد البيانات داخل المشروع.

## البيانات والاستقلال

> تنبيه: لا تفترض أن الإنشاء ينسخ بيانات Production تلقائيًا أو يضيف بيانات تجريبية أو يعطّل البريد الصادر والمهام المجدولة والمدفوعات والتكاملات. تحقّق من قواعد البيانات الفعلية واضبط التطبيق بما يناسب الاختبار قبل استخدامه.

Staging وDevelopment بيئتان مستقلتان في التشغيل والبيانات. لا تخضع أدوات قواعد البيانات فيهما لحد قاعدة العميل الواحدة في Production، مع بقاء قيود سعة التخزين.

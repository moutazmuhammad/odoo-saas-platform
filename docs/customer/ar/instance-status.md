# مرجع حالات Instance

افهم حالات الدفع والتجهيز والتشغيل والإخفاق.

تاريخ المراجعة: 2026-10-05

## معاني الحالات

| الحالة | المعنى والإجراء التالي |
| --- | --- |
| Pending payment | لم يكتمل الدفع. سدّد الفاتورة لتفعيل الطلب. |
| Paid / Pending provision | سُجّل الدفع، ويجري انتظار تخصيص الموارد أو جاهزية البنية. |
| Provisioning | تجري عملية في الخلفية ضمن دورة الخدمة. راجع تفاصيلها قبل إعادة المحاولة. |
| Running | التطبيق يعمل، وقد تحتاج الاستضافة إلى إنشاء قاعدة بيانات للعميل. |
| Stopped | التطبيق متوقف مع بقاء السعة والاشتراك. |
| Suspended | أوقف قيد مثل تجديد غير مدفوع أو امتلاء السعة التشغيل مؤقتًا. |
| Failed | أخفقت عملية. راجع رسالة الخطأ وسجل Deployment. |
| Cancelled | أزيلت البنية أو اكتمل إلغاء الخدمة. |

## عمليات الخلفية

قد يستمر الإنشاء وDeployment والاستعادة والحذف بعد قبول الطلب. تحديث المتصفح لا يعني اكتمال العملية. تنظّم المنصة العمليات المتعارضة وتوفّر إعادة المحاولة ومعالجة العمليات المتعثرة، لكن أعطال الشبكة أو السعة أو Git أو التخزين قد تستلزم تدخل الدعم.

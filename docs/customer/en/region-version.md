# Choose a region, Odoo version, and edition

Match application compatibility and infrastructure availability.

Reviewed: 2026-10-05

## Region

Choose among active regions offered in the configurator. A nearby location can reduce network latency, but the actual placement also depends on healthy available capacity. Region is not a self-service move setting after creation; moving requires a planned new deployment and data transfer.

## Version and edition

The website lists Odoo 13 through Odoo 20. An advertised version is selectable only when its catalog record and compatible runtime image are enabled. Community and Enterprise are distinct editions. Match your modules and backup to the selected major version; changing a plan does not migrate a database to another Odoo major version.

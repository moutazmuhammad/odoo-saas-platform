# إدارة متطلبات Python

حدّد متطلبات حزم قابلة لإعادة البناء داخل مستودعك.

تاريخ المراجعة: 2026-10-05

## استخدام requirements.txt

تأتي متطلبات Python من ملف `requirements.txt` في مستودعك، وليس من قائمة حزم تُدخل يدويًا في لوحة التحكم. أضف الملف إلى Git ثم نفّذ Deployment للفرع المعني. ثبّت أرقام إصدارات متوافقة لإعادة البناء بشكل متوقع. يتحقق البناء من المتطلبات ويستخدم طبقات الحزم المخزّنة مؤقتًا؛ وقد يستغرق تغيير الحزم وقتًا أطول من تغيير الكود وحده.

```text
phonenumbers==9.0.40
# Add only dependencies needed by your modules.
```

## معالجة إخفاق المتطلبات

1. اقرأ مخرجات البناء المخفق لتحديد الحزمة أو الإصدار أو خطأ التحقق.
2. تحقق من التوافق مع Odoo وPython المختارين ومن إتاحة الحزمة في مصدر الحزم المدعوم.
3. صحّح requirements.txt وأضفه إلى Git، ثم ادفع الفرع أو اطلب إعادة Deployment.

لا تعتمد على تثبيت الحزم في Terminal كإعداد دائم. يستبدل Deployment الـ Containers، ولذلك يجب تضمين المتطلبات الدائمة في بناء الصورة. ملف المتطلبات لا يوفّر أي حزمة لنظام التشغيل تلقائيًا.

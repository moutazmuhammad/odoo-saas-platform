# أسئلة العملاء الشائعة

إجابات سريعة وروابط إلى أدلة الاستخدام الكاملة.

تاريخ المراجعة: 2026-10-05

## هل يستطيع عضو الفريق امتلاك مشاريع؟

نعم، بعد إكمال إعداد الحساب المطلوب. تفصل القائمة بين مشاريعه والمشاريع التي شاركها معه مالك آخر. ملكية مشروع لا تمنحه صلاحيات المالك في المشاريع المشتركة. راجع [الفريق والصلاحيات](iam-overview.md).

## هل يمكن استبدال قاعدة Production؟

نعم. استعد إلى القاعدة الموجودة مع الاستبدال، أو انسخها احتياطيًا واحذفها قبل إنشاء أخرى. احتفظ بقاعدة عميل واحدة. راجع [استعادة قاعدة بيانات](database-restore.md).

## هل يوقف حذف Staging تكلفة سعتها؟

يحرّر الحذف مكان الخادم لإعادة الاستخدام. حرّر المكان المحجوز الشاغر لتقليل تكلفة السعة المتكررة والحصول على رصيد الوقت غير المستخدم المؤهل. راجع [سعة البيئات](environment-slots.md).

## هل ينقل الدمج البيانات الفعلية؟

لا. يغيّر الدمج كود Git. انسخ القواعد صراحة إلى Staging أو Development، واستخدم الاستعادة للاستبدال المخطط. راجع [دمج الكود](environment-merge.md) و[نسخ القواعد](environment-copy.md).

## هل يوقف إيقاف Instance أو تعطيل التجديد التلقائي الفوترة؟

لا. الإيقاف يغيّر التشغيل، وتعطيل التجديد يغيّر الخصم التلقائي. قد تستمر الفواتير والسعة المحجوزة حتى إلغاء الاشتراك أو تحرير السعة المعنية. راجع [التجديد التلقائي](auto-renew.md).

## هل يحدّث كل تغيير للكود جميع الوحدات؟

لا. يختار البناء وحدات المستودع التي تغيرت مدخلات تحديثها. عادةً يُنشر تعديل التشغيل وحده دون تحديث وحدة. وقد يختار البناء الأول، دون أساس سابق، كل وحدات المستودع المكتشفة. راجع [التحديث الانتقائي للوحدات](module-upgrades.md).

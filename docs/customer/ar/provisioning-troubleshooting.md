# معالجة مشروع عالق في التجهيز

حدّد العملية الجارية واجمع المعلومات قبل إعادة المحاولة.

تاريخ المراجعة: 2026-10-05

## الفحص بالترتيب

1. تحقق من تسوية الدفع؛ انتظار الدفع لا يعني اكتمال الإطلاق.
2. اقرأ الحالة والعملية؛ فقد يعني التجهيز استعادة أو إلغاء أو إجراءً آخر في الخلفية.
3. لـ Deployment الأول، راجع السجل إن سمحت صلاحياتك وحدّد ما إذا كان بناء الصورة أو التشغيل جاريًا.
4. حدّث الحالة بعد فترة مناسبة بدل إنشاء مشاريع مكررة أو إعادة طلبات الحذف والاستبدال.
5. إذا توقف التقدم، أرسل للدعم المشروع والبيئة ووقت البدء ومرجع الفاتورة ومرحلة البناء والخطأ الظاهر.

## أسباب شائعة

قد يتأخر الإطلاق بسبب تخصيص السعة أو تعذّر المنطقة أو Cluster أو جلب الصورة أو TLS أو اعتمادات Git أو بناء المتطلبات أو جاهزية القاعدة أو فحوص البنية. وجود إعادة المحاولة والمعالجة في الخلفية لا يعني إصلاح كل خطأ تلقائيًا. لا ترسل كلمات مرور الخوادم أو Tokens عند طلب المساعدة.

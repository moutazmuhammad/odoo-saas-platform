# منح وصول المشروع وإلغاؤه

عيّن أدوارًا ثابتة لأعضاء أو مجموعات عبر المشاريع المختارة.

تاريخ المراجعة: 2026-10-05

## منح الوصول

1. افتح **الفريق والصلاحيات** من التنقل العام أو المشروع، وتحقق من مساحة العمل عبر تصفية العميل والمشروع.
2. اختر **منح الوصول** وحدّد عضوًا موجودًا أو مجموعة ثم المشاريع. أضف العضو أولًا إذا لم يظهر.
3. حدّد الأدوار الثابتة ونطاق Production أو Staging أو Development أو الكل، وراجع الأدوار التي تتيح الحذف قبل الحفظ.
4. راجع صفوف الأدوار الناتجة واطلب من العضو إكمال إعداد حسابه أو قبول الدعوة عند الحاجة.

## إلغاء الوصول

ألغِ منح الأدوار المعنية وراجع عضوية المجموعات أيضًا. يجمع الوصول الفعلي المنح المباشرة ومنح المجموعات؛ وإلغاء مسار لا يلغي الآخر. يمنع الإلغاء فحوص الصلاحية اللاحقة ويغلق Terminal التي فقدت صلاحيتها ويلغي العمل المنتظر غير المصرّح به. قد يكتمل العمل الجاري، وتبقى البيانات المنزّلة خارج سيطرة المنصة.

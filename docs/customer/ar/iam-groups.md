# إدارة مجموعات الفريق

امنح الوصول لمجموعة وأدر عضويتها.

تاريخ المراجعة: 2026-10-05

## إنشاء مجموعة واستخدامها

1. بصفتك المالك، افتح تبويب المجموعات في الفريق والصلاحيات وأنشئ مجموعة باسم واضح.
2. أضف أعضاء الفريق المرتبطين بالحساب. تتيح ملفات الأعضاء أو الدعوات المقبولة اختيارهم للفريق.
3. امنح المجموعة أدوارًا ثابتة على المشاريع والبيئات المحددة كما تفعل للعضو الفردي.
4. راجع العضوية دوريًا. إزالة عضو تلغي وصول المجموعة، لكن أدواره المباشرة أو عضويته في مجموعة أخرى قد تظل تمنحه صلاحيات.

## الإدارة والحذف

يدير مالك حساب العميل وحده عضوية المجموعات. يستطيع مسؤول صلاحيات المشروع منح أدوار للمجموعات المؤهلة ضمن حدود تفويضه، لكنه لا يدير فريق العميل بالكامل. يعطّل حذف المجموعة وصولها دون حذف حسابات أعضائها.

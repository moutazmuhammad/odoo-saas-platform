# إنشاء نسخة مطابقة من قاعدة البيانات

أنشئ نسخة مستقلة عندما تسمح السعة بذلك.

تاريخ المراجعة: 2026-10-05

## المتطلبات

إنشاء النسخة المطابقة إجراء للاستضافة في بيئة تعمل. تحتاج **مسؤول إنشاء قواعد البيانات** و**مسؤول تنزيل النسخ الاحتياطية** لأن العملية تنسخ بيانات المصدر. يمنع حد قاعدة Production الواحدة عادةً إنشاء نسخة إضافية على Instance نفسها؛ استخدم بدلًا من ذلك النسخ إلى Staging أو Development.

## خطوات إنشاء النسخة

1. اختر قاعدة المصدر ثم إنشاء نسخة مطابقة.
2. أدخل اسمًا جديدًا صالحًا وتأكد من وجود سعة تخزين كافية.
3. أكّد وانتظر اكتمال العملية في الخلفية قبل فتح النسخة.

> تنبيه: تصبح للنسخة بيانات مستقلة بعد الإنشاء. راجع المهام المجدولة والبريد ومزوّدي الدفع والتكاملات الخارجية قبل استخدامها للاختبار؛ فنسخ القاعدة لا يضمن تعطيل اتصالاتها الفعلية.

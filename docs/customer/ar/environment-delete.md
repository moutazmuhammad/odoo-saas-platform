# حذف بيئة أو فرع Git الخاص بها

احذف خادمًا غير رئيسي وحدّد ما إذا كنت تريد الاحتفاظ بفرعه.

تاريخ المراجعة: 2026-10-05

## قبل الحذف

> تنبيه: يحذف الإجراء قواعد البيئة وملفاتها وسجلات التشغيل الفعلية بصورة نهائية. نزّل النسخ التي تحتاجها أولًا. لا تحذف هذه الأداة Production؛ فإلغاء المشروع إجراء مستقل.

تحتاج دور **مسؤول حذف البيئات** لنوع البيئة المستهدفة. يحرّر حذف الخادم مكانه لإعادة الاستخدام، لكنه لا يلغي حجز السعة أو يعيد قيمتها بحد ذاته.

## الحذف بأمان

1. اختر بيئة Staging أو Development ثم الحذف.
2. اترك حذف الفرع البعيد غير محدّد للاحتفاظ بالكود. حدّده فقط إذا لم تعد تحتاج الفرع.
3. اكتب اسم البيئة المطلوب في نافذة التأكيد كما هو ثم أكّد.
4. انتظر اكتمال الإزالة. إذا رُفض حذف الفرع فراجع صلاحيات المزوّد والفرع الافتراضي أو المحمي، وتأكد من أن الفرع ما زال موجودًا.

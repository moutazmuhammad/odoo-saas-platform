# استخدام الفترة التجريبية

تعرّف على إتاحة التجربة وحدودها والانتقال إلى اشتراك مدفوع.

تاريخ المراجعة: 2026-10-05

## الإتاحة والحدود

تتاح التجربة عند تفعيلها ووجود خطة تجريبية مؤهلة. تضبط المنصة المدة وشروط الاستحقاق؛ واعتمد على تاريخ الانتهاء المعروض في لوحة التحكم. يلزم الانتقال إلى خطة مدفوعة قبل شراء النسخ اليومية أو ترقيات موارد التشغيل المدفوعة أو سعة بيئات إضافية.

## الانتقال إلى خطة مدفوعة

1. افتح Instance التجريبية واختر **ترقية الخطة**.
2. اختر خطة مدفوعة ودورة فوترة ثم سدّد الفاتورة.
3. تأكد من ظهور الخطة المدفوعة وحالة التشغيل قبل الاعتماد عليها لخدمة فعلية.

> تنبيه: عند انتهاء التجربة يتوقف التشغيل أو يُعلّق وفق سياسة دورة الخدمة. لا تفترض الاحتفاظ بالبيانات إلى أجل غير محدد أو تضمين النسخ الاحتياطية؛ صدّر البيانات المهمة قبل انتهاء التجربة.

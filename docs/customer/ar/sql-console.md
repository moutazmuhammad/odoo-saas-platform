# تشغيل استعلامات SQL للقراءة فقط

استكشف قاعدة البيانات دون استخدام الأداة لتعديلها.

تاريخ المراجعة: 2026-10-05

## المتطلبات والحدود

استخدم بيئة استضافة تعمل ودور **مسؤول SQL**، واختر قاعدة من قائمة البيئة. تعمل الاستعلامات داخل معاملة PostgreSQL للقراءة فقط ويُتراجع عنها عند الانتهاء. تُرفض الكتابة وتغييرات البنية؛ فلا تستخدم الأداة لتعديل القاعدة. الافتراضي 1000 صف، ويحد Backend الحد المطلوب عند 10000.

## تشغيل الاستعلام وقراءة النتيجة

1. افتح SQL واختر القاعدة واكتب الاستعلام بأسماء الجداول والحقول الفعلية.
2. اختر التشغيل أو اضغط Ctrl/⌘ + Enter.
3. راجع الأعمدة والصفوف وقيم null ومؤشر اقتطاع النتائج. أضف LIMIT أصغر أو شرط تصفية عند الحاجة.

```sql
SELECT id, name
FROM res_partner
ORDER BY id
LIMIT 20;
```

## أخطاء الاستعلام

تعرض الأداة أخطاء صياغة SQL والصلاحيات لتصحيح الاستعلام. قد تكشف القراءة بيانات حساسة داخل القاعدة المختارة؛ لذا امنح الدور للمستخدمين الموثوقين فقط. تجنّب الاستعلامات المكلفة غير المحدودة في Production.

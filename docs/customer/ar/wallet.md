# فهم رصيد حسابك

ميّز رصيدك المدفوع عن الرصيد الممنوح القابل للانتهاء.

تاريخ المراجعة: 2026-10-05

## أنواع الرصيد

| النوع | السلوك |
| --- | --- |
| رصيدك | لا تنتهي القيمة المدفوعة مسبقًا والقيمة المدفوعة المعادة المؤهلة. |
| الرصيد الإضافي | قد ينتهي الرصيد الذي تمنحه المنصة؛ راجع تاريخ انتهاء حسابك. |

## استخدام الرصيد

تستخدم المشتريات المؤهلة رصيد المحفظة المتاح تلقائيًا حتى إجمالي البنود قبل التسوية. يُستهلك الرصيد القابل للانتهاء قبل الرصيد المدفوع. يعيد إلغاء الفاتورة الرصيد المحجوز المرتبط إلى نوعه وتاريخ انتهائه الأصليين. راجع الرصيد وسجل الحركات وبند الرصيد في الفاتورة؛ فرصيد المحفظة قيمة داخل حساب المنصة وليس وعدًا بسحب نقدي أو استرداد بنكي.

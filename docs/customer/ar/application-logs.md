# عرض سجلات التطبيق وتنزيلها

تابع مخرجات التشغيل واحفظ المعلومات المفيدة للتشخيص.

تاريخ المراجعة: 2026-10-05

## استخدام تبويب السجلات

السجلات خاصية للاستضافة وتتطلب بيئة تعمل ودور **قارئ السجلات**. افتح السجلات للبيئة المختارة. تميّز الألوان الأخطاء والتنبيهات ورسائل Debug والرسائل العادية. استخدم الإيقاف المؤقت والاستئناف والتمرير التلقائي والمسح والتنزيل لمراجعة المخرجات. المسح يزيل عرض المتصفح ولا يطلب حذف سجلات الخادم الدائمة.

## حدود البث واللغة

تحتفظ الصفحة بعدد محدود من الرسائل الحديثة في المتصفح، وليست أرشيفًا غير محدود. يحفظ التنزيل المخرجات التي جمعتها الصفحة، لا كل السجلات السابقة. قد ينتهي البث بسبب توقف البيئة أو تغيّر الصلاحيات أو انقطاع الاتصال أو انتهاء مدة البث. استأنفه بعد معالجة السبب. تبقى السجلات التقنية من اليسار إلى اليمين في العربية دون ترجمة محتوياتها أو توقيتها.

## إرسال معلومات مفيدة

أرسل اسم البيئة والخطأ كما ظهر والأسطر المحيطة به ووقت الحدث عند التواصل مع الدعم. أزل Tokens وكلمات المرور وبيانات العملاء غير اللازمة. مخرجات Deployment موجودة في سجل مستقل وتتطلب كذلك قارئ السجلات.

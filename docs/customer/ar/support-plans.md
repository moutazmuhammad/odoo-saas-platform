# اختيار خطة الدعم وطلب المساعدة

اعتمد شروط الدعم المنشورة وأرسل معلومات تساعد على التشخيص.

تاريخ المراجعة: 2026-10-05

## شروط الدعم

تعرض صفحة الإعداد خطط الدعم النشطة ووصفها ورسومها. قد تكون الخطة المجانية حسب الإمكانات، وقد تتضمن المدفوعة أهداف استجابة مختلفة. اعتمد الشروط المنشورة للخطة لمعرفة الالتزام المحدد. هدف الاستجابة ليس ضمانًا لمدة الحل أو اتفاقية توافر أو خدمة تطوير غير محدودة.

## إعداد طلب دعم مفيد

1. أرسل المشروع والبيئة وإصدار Odoo والصفحة أو العملية المحددة.
2. اشرح السلوك المتوقع والفعلي وخطوات إعادة المشكلة ووقتها مع المنطقة الزمنية.
3. أرفق مخرجات الخطأ المناسبة أو مراجع الفاتورة والدفع، وأزل الاعتمادات والبيانات الشخصية غير اللازمة.
4. استخدم قناة الدعم المنشورة في الموقع؛ تغيير الخطة لا ينشئ طلب دعم تلقائيًا.

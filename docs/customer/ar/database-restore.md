# استعادة قاعدة بيانات من نسخة محلية

ارفع نسخة Odoo واستعدها إلى قاعدة جديدة أو موجودة.

تاريخ المراجعة: 2026-10-05

## قبل البدء

استخدم بيئة استضافة تعمل ودور **مسؤول استعادة قواعد البيانات**. اختر نسخة تتوافق مع إصدار Odoo والكود المثبت في البيئة. تقبل نافذة الرفع أرشيفات نسخ Odoo المدعومة؛ ويفضل ZIP يحتوي مجلد المرفقات. تفريغ قاعدة البيانات وحده لا يشمل المرفقات.

## الرفع والاستعادة

1. اختر الاستعادة من قواعد البيانات وحدّد الملف، ثم اسم قاعدة جديدة أو استبدال قاعدة موجودة.
2. في Production استبدل قاعدة العميل الموجودة، أو احذفها قبل الاستعادة باسم آخر. عند الاستبدال اكتب اسم الهدف الكامل المطلوب في النافذة كما هو.
3. أبقِ المتصفح مفتوحًا أثناء الرفع. ينتقل الملف مباشرة إلى التخزين وتظهر نسبة التقدم.
4. بعد اكتمال الرفع تتحقق المنصة من الأرشيف وتبدأ الاستعادة في الخلفية. تابع العملية حتى تكتمل أو تعرض خطأ.
5. افتح القاعدة المستعادة ببيانات دخول التطبيق الأصلية، وأعد تعيين كلمة مرور المسؤول عند الحاجة إذا كنت تملك الصلاحية.

## الاستبدال والتوافق

> تنبيه: يمحو الاستبدال بيانات الهدف الحالية. نزّل نسخة جديدة من الهدف قبل التأكيد. التحقق من الأرشيف لا يضمن توافق كل وحدة مخصصة أو تكامل خارجي أو اختلاف في الإصدار الرئيسي.

# إطلاق مشروع الاستضافة الأول

حدّد اشتراكك وأكمل الدفع ثم جهّز قاعدة بياناتك.

تاريخ المراجعة: 2026-10-05

## قبل البدء

سجّل الدخول بحساب مكتمل الإعداد، واختر إصدار Odoo ونسخته والمنطقة والخطة المناسبة. يعرض التسعير وصفحة الدفع الأسعار الحالية؛ ولا تحدد هذه الوثائق أسعارًا ثابتة أو مدة مضمونة للتجهيز.

## الإعداد والإطلاق

1. افتح **الاستضافة**، واختر خطة أو موارد مخصصة، ثم أدخل اسم المشروع ونطاقًا فرعيًا متاحًا.
2. حدّد إصدار Odoo والمنطقة وWorkers والتخزين ودورة الفوترة والإضافات الاختيارية المعروضة.
3. راجع الإجمالي وأكمل الدفع. يبدأ تجهيز الاشتراك المدفوع بعد تسوية الفاتورة، بينما تتوقف إتاحة التجربة على إعدادات المنصة.
4. تابع حالة Instance حتى تعمل، ثم افتح **قواعد البيانات** لإنشاء قاعدة أو استعادة نسخة Odoo موجودة.
5. افتح Odoo من صف قاعدة البيانات وسجّل ببيانات مسؤول هذه القاعدة.

## بعد الإطلاق

يُربط مستودع Git بعد الشراء من **الكود والحزم**. شراء سعة Staging وDevelopment يحجز أماكن للبيئات، لكنه لا ينشئ خوادمها تلقائيًا عند الدفع. يعرض موقع الاستضافة صفحة عدم وجود قاعدة بيانات إلى أن تُنشأ قاعدة للعميل.

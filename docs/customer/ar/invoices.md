# عرض الفواتير وسدادها

اقرأ حالة الفاتورة وبنودها ورصيدها ونتيجة الدفع.

تاريخ المراجعة: 2026-10-05

## الوصول إلى الفاتورة

افتح الفوترة بحساب مالك العميل. اختر فاتورة لعرض البنود والتواريخ والإجمالي والمبلغ المتبقي، واستخدم الدفع أو تنزيل PDF عند إتاحتهما. أدوار المشاريع للأعضاء لا تكشف سجلات المالك المالية.

| الحالة | المعنى |
| --- | --- |
| Open | صادرة وتنتظر التسوية. |
| Overdue | غير مدفوعة بعد تاريخ الاستحقاق المعروض. |
| Partially paid | تحتاج تسوية المبلغ المتبقي. |
| Paid | سُجّل الدفع وسُوّيت الفاتورة. |

## إكمال الدفع

استخدم مزوّد الدفع المتاح ثم ارجع إلى صفحة الفاتورة أو Instance. نجاح الدفع لدى المزوّد لا يعني اكتمال تسويته داخل المنصة؛ تحقق من ظهور الدفع وتطبيق التفعيل المطلوب. إذا خُصم المبلغ وبقيت الفاتورة مفتوحة، لا تكرر الدفع. أرسل للدعم الفاتورة ومعرّف عملية المزوّد دون بيانات البطاقة الكاملة.

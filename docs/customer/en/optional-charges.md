# Decline optional charges and understand proration

Cancel an optional purchase without confusing it with a renewal obligation.

Reviewed: 2026-10-05

## Optional invoices

A Decline or cancel-charge action appears only for eligible unpaid optional invoices, such as a requested upgrade or capacity/add-on purchase. It cancels that request and handles linked reserved credit. It is not a way to decline an active subscription renewal or undo an already applied paid change.

## Unused time and credit

Mid-cycle purchases can be prorated to the renewal date. Plan upgrades account for unused prepaid value through the quote, invoices, and wallet. Releasing unused environment slots can credit their remaining cycle value to the wallet. Deleting the server alone keeps its slot reserved. Review the actual charge and credit shown before confirming.

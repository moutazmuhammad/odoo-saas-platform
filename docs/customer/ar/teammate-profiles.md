# إضافة أعضاء الفريق وإدارتهم

أنشئ حسابًا مُدارًا أو اربط حسابًا موجودًا دون التحكم ببيانات دخوله.

تاريخ المراجعة: 2026-10-05

## إضافة عضو

1. بصفتك مالك حساب العميل، افتح **الفريق والصلاحيات ← أعضاء الفريق ← إضافة عضو الفريق**.
2. أدخل الاسم والبريد. الهاتف اختياري عند الإنشاء؛ اختر الدولة لإضافة مفتاحها وتحقق من الرقم النهائي.
3. أنشئ الملف. يعرض الحساب المُدار الجديد كلمة مرور مؤقتة مرة واحدة. احفظها أو شاركها قبل إغلاق النافذة.
4. عيّن الأدوار المطلوبة بشكل مستقل. إنشاء الملف وحده لا يمنح إجراءات المشروع.

## الحسابات الموجودة والمشتركة

تحتفظ الحسابات المستقلة الموجودة بكلمات مرورها وبياناتها. تحتاج الحسابات التي يديرها عميل آخر إلى دعوة مقبولة قبل الربط. لا يعيد المالك تعيين دخول مستقل أو مشترك، ولا يتحكم بحساب له مشاريعه أو سجلات فوترة خاصة به. تشمل فحوص الهاتف الأرقام بعد توحيد صيغتها وحسابات الدخول غير النشطة.

## حذف ملف عضو

يحذف ملف العضو المنح المباشرة وعضوية المجموعات والدعوات لهذا العميل. يبقى الدخول الموثّق أو المستقل أو المشترك متاحًا لصاحبه ومشاريعه الأخرى. قد يُعطّل الحساب غير الموثّق المستخدم حصريًا للفريق. حذف ملف العضو لا يعني حذف حسابه الموثّق.

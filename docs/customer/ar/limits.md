# مرجع الحدود والإتاحة

راجع الحدود الافتراضية والخصائص التي تعتمد على إعدادات المنصة.

تاريخ المراجعة: 2026-10-05

## الحدود التي تهم العميل

| المجال | السلوك الحالي |
| --- | --- |
| Production hosting database | قاعدة واحدة للعميل (1)؛ ويسمح بالاستبدال. |
| Staging / Development databases | لا يحدد عدد ثابت في اللوحة؛ مع تطبيق سعة تخزين البيئة. |
| Registration / recovery password | 8 أحرف على الأقل. |
| Managed teammate first password | 12 حرفًا على الأقل ومختلفة عن المؤقتة. |
| Database administrator reset | 6 أحرف على الأقل؛ واختر كلمة أقوى. |
| Teammate verification | رمز لمدة 10 دقائق؛ 5 محاولات خاطئة؛ وحدود لمعدل الإرسال والتحقق. |
| Invitation | تنتهي بعد 7 أيام ويجب أن تطابق بريد دخول المستلم. |
| SQL result | 1000 صف افتراضيًا؛ حتى 10000 للحد المطلوب. |
| Metrics history | حتى 14 يومًا حسب إتاحة بيانات المراقبة. |
| Deployment history | الافتراضي: 30 يومًا / 50 سجلًا مكتملًا؛ وقد تبقى السجلات المحمية أطول. |
| Daily snapshots | الافتراضي 7 نسخ يومية حديثة حسب نجاح الالتقاط. |
| Idle Shell | نحو 10 دقائق قبل تنظيف الجلسة الخاملة. |

## الإتاحة حسب الإعداد

تضبط المنصة الإصدارات وصور Enterprise والمناطق والتجربة والأسعار وأحجام إضافات التخزين وشروط الدعم والبريد وWhatsApp ومزوّدي الدفع. يُعتمد الكتالوج الحالي والدفع قبل أمثلة الأدلة. لا تعرض لوحة التحكم الحالية إدارة حسابات خدمة أو مفاتيح API للعميل أو محرر أدوار مخصصة أو هيكل مجلدات أو ترحيلًا ذاتيًا لإصدار رئيسي. تواصل مع الدعم للاحتياجات خارج الواجهة، بما فيها Domain مخصص أو نقل المنطقة.

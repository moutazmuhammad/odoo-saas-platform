# دمج الكود بين البيئات

انقل تغييرات فرع Git إلى الفرع المستهدف دون نسخ البيانات.

تاريخ المراجعة: 2026-10-05

## قبل الدمج

اختر بيئتين داخل المشروع نفسه ولهما مستودع مرتبط. تحتاج وصول عرض المشروع في المصدر ودور **مسؤول Deployment** في الهدف. راجع اسمي الفرعين واختبر كود المصدر قبل الدمج إلى Production. يجب أن يسمح اعتماد المستودع بعملية الدمج لدى المزوّد.

## الدمج والتحقق

1. استخدم إجراء الدمج في مساحة العمل، أو اسحب بيئة المصدر إلى الهدف عندما تتيح الواجهة ذلك.
2. راجع الاتجاه: تنتقل تغييرات المصدر إلى فرع الهدف، ثم أكّد الدمج.
3. إذا نجح الدمج لدى المزوّد وكان الهدف يعمل أو متوقفًا، تطلب المنصة إعادة Deployment للهدف. تابع السجل.
4. عالج تعارضات Git أو قيود الفرع المحمي لدى مزوّد Git، ثم أعد المحاولة عند الحاجة.

## الكود مستقل عن البيانات

> تنبيه: الدمج لا ينسخ قواعد البيانات ولا يستبدلها. كذلك لا يعكس التراجع عن Deployment تغييرات قاعدة البيانات. احتفظ بنسخة من البيانات الفعلية قبل تعديل بنية القاعدة أو البيانات التي يحمّلها Odoo.

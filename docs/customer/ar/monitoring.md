# مراقبة استخدام الموارد

اقرأ المقاييس المباشرة والسجل دون تفسير غياب البيانات باعتباره استخدامًا صفريًا.

تاريخ المراجعة: 2026-10-05

## المقاييس والفترات

يشمل عرض المشروع معلومات CPU وRAM والتخزين. تميّز المقاييس المباشرة بين حصة Odoo وحصة قاعدة البيانات عند توفرها. يعرض تبويب المقاييس فترات 1h و6h و24h و7d و14d. تُقاس القيم بالنسبة إلى الموارد المخصصة وقد تكون عينات أو قياسات مخزّنة مؤقتًا؛ وليست قياسًا لأداء كل مستخدم.

## قراءة المخططات

1. اختر البيئة والفترة التي تشمل وقت البطء المبلّغ عنه.
2. قارن الضغط المستمر مع Deployment والمهام المجدولة والاستيراد وأوقات ازدحام العمل.
3. اعتبر المقاييس غير المتاحة والفجوات بيانات مفقودة، لا دليلًا على سلامة Instance أو خمولها.
4. استخدم السجلات وSQL للقراءة فقط لفهم السلوك المكلف قبل اتخاذ قرار زيادة الموارد.

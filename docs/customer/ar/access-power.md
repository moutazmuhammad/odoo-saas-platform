# بدء تشغيل Instance وإيقافها وإعادة تشغيلها

تحكّم بالتشغيل وافهم الفرق بين الإيقاف وإلغاء الاشتراك.

تاريخ المراجعة: 2026-10-05

## قبل البدء

استخدم حساب المالك أو دور **مسؤول تشغيل Instance** في البيئة المختارة. انتظر اكتمال العملية الجارية قبل إرسال أمر آخر. بيانات الدخول إلى التطبيق مستقلة عن بيانات دخول VELTNEX.

## أوامر التشغيل

| الإجراء | النتيجة |
| --- | --- |
| Start | يشغّل Instance متوقفة. |
| Stop | يوقف التطبيق دون إلغاء الاشتراك أو تحرير السعة المدفوعة. |
| Restart | يعيد تشغيل التطبيق وقد يقطع الطلبات الجارية. |

افتح ملخص البيئة واختر أمر التشغيل المتاح، ثم تابع الحالة حتى تستقر. إذا كانت Instance معلّقة بسبب الفوترة أو امتلاء التخزين، عالج السبب؛ أمر بدء التشغيل لا يتجاوز هذه القيود.

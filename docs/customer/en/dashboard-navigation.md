# Dashboard search and notifications

Navigate quickly and understand which alerts the dashboard displays.

Reviewed: 2026-10-05

## Search and navigation

Use the top search control or Ctrl/⌘ + K to open the command palette. Search available projects, pages, and actions; use arrow keys and Enter to select and Escape to close. The project selector separates owned and shared projects. Choosing a search result never adds permissions to a restricted environment.

## Notifications and action items

The dashboard highlights outstanding checkout and invoices, failed or suspended instances, and other available account signals. The header bell summarizes account signals and links to their pages; it is not a permanent notification archive or a configurable alert-rule system. Review the underlying invoice or instance status before acting. Teammates see only the data their permissions allow.

# استخدام Shell من المتصفح

افتح Terminal محددة النطاق وافهم حدود الجلسة واستمرار التغييرات.

تاريخ المراجعة: 2026-10-05

## الوصول وحدوده

Shell أداة للاستضافة وتتطلب بيئة تعمل ودور **مسؤول Terminal**. تفتح Terminal العميل الـ Container المخصصة لـ Shell داخل Instance، وليس مضيف Kubernetes أو Terminal مسؤول المنصة. لا تكشف بيانات القاعدة أو كلمة المرور الرئيسية للتطبيق.

## فتح الجلسة وإغلاقها

1. اختر البيئة الصحيحة وافتح Shell، وانتظر إذا كانت Container الوصول لا تزال قيد التجهيز.
2. شغّل أوامر التشخيص التي تدعمها الأدوات والبيئة. لا تفترض وصول root أو توفر اعتمادات قاعدة التطبيق.
3. أغلق Terminal عند الانتهاء، وأعد الاتصال إذا انتهت الجلسة أو أُعيد Deployment للبيئة.

## الجلسة واستمرار التغييرات

تُنظّف جلسات Terminal الخاملة بعد نحو 10 دقائق. لا تحفظ Containers التي تُستبدل أي تعديل محلي أو حزمة مثبّتة تلقائيًا. ضع الكود الدائم ومتطلبات Python في Git وإعداد البناء. تعامل مع الأوامر كإجراءات فعلية داخل البيئة المحددة، ولا تشارك مخرجات تحتوي بيانات خاصة.
